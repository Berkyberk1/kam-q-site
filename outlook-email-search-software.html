What goes wrong with Outlook search

Outlook search can be slow, and it can miss mail that is plainly in the mailbox. The usual causes and fixes are in Why Outlook search is slow or missing emails. When rebuilding the index does not help, a separate search tool is the next step.

What KAM-Q does

  • Search as you type. Type any part of a subject, a name, an address, a folder or an attachment name, in any order. Combine terms with AND, OR and NOT, or use quoted phrases.
  • Find it by who sent it. The People view ranks everyone who writes to you and lists every file each person has sent. See how to find attachments from a specific sender.
  • Find files by name. KAM-Q searches attachments by file name and by the subject of the message they arrived with.
  • Large mailboxes. KAM-Q reads newest mail first, so you can search within minutes while the rest loads. Our demonstration mailbox holds 406,436 messages.

What it does not do

  • It does not read the text inside attached files. It finds attachments by file name.
  • The Outlook versions are read only. They never send, move or delete a message.
  • The Windows and Mac apps need classic Outlook, not the new Outlook. If you use the new Outlook, use the browser version with a Microsoft 365 or Outlook.com account.

Where it runs

Windows 10 or 11 with classic Outlook. macOS 11 or later with classic Outlook for Mac or Apple Mail. Any modern browser with a Microsoft 365, Outlook.com or Gmail account. The browser version is free and needs no license. One license covers four installations of the Windows and Mac apps. Full requirements are on the download page.
