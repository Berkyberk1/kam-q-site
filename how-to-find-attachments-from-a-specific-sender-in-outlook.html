How to find attachments from a specific sender in Outlook

Remember who sent the file, but not which email it was in? KAM-Q’s People view lists every file a sender has sent, searchable by file name or subject.

Updated October 28, 2026

Quick answer in classic Outlook: search for from:alex@example.com hasattachments:yes, replacing the example address with your sender’s address. Check the search scope, then open a matching message to find its files. See the Outlook steps.

Browse a sender’s files in KAM-Q

Outlook filters messages by sender and whether they have attachments. You then open the matching messages to inspect their files. In KAM-Q, select a person in People and browse their attachment list, newest first.

  1. Open classic Outlook and KAM-Q. Keep Outlook open while using the Windows app.
  2. Choose the folders to include. Include the folders where this sender’s messages are stored, and let KAM-Q index them. The list reflects the mail indexed so far.
  3. Open People and select the sender. Check the person’s name and address to identify the right sender.
  4. Browse their attachments. Review the files, newest first. Open a file, or open the email it came from to check the surrounding conversation.
  5. Search inside that person’s files. A sender you have worked with for years can have hundreds of files in the list. Type in the box above it to narrow them. It matches the file name and the subject of the email the file arrived with, so either one will find it.

That last step is the difference worth knowing about. Outlook can filter messages by sender and by whether they have attachments, but you are still opening messages to see what is inside them. In KAM-Q you are looking at the files themselves, and searching the files themselves.

It helps when you remember the file only partly. If you recall that it was a purchase order but not its number, search purchase order and you get every file whose name or covering email says so. Searching a file name is different from searching the text inside a document, which KAM-Q does not do.

For example, a supplier may have sent a quotation and then a revision. Browse that supplier’s files and check the original emails to confirm which version you need. Compare dates and names; a repeated file name does not establish that the contents are the same.

KAM-Q reads Outlook mail and keeps its own index on your computer. The Outlook version does not send, move, or delete messages. It cannot show files from mail that has not been included and indexed.

Use Outlook’s built-in search

You can find attached files with Outlook alone. Its sender and attachment filters return the messages you need to inspect.

Classic Outlook: sender and attachment search steps
  1. Open Mail and click the Search box above the message list.
  2. Enter from:alex@example.com hasattachments:yes with the actual sender address, then press Enter. The from: operator limits the sender; an address typed alone can match text elsewhere.
  3. Check the scope selector. Choose Current Mailbox, Current Folder, or All Mailboxes as appropriate for where the message is stored.
  4. Open a matching message and review its attached files.

To use the ribbon instead, click Search, select From in the Refine group and supply the sender, then select Has Attachments. Labels can vary slightly by Outlook version.

If you remember a subject word, try from:alex@example.com hasattachments:yes subject:proposal. This narrows the message subject; it does not require the file to be named “proposal.”

New Outlook or Outlook on the web

Use Outlook’s search filter button at the right of the Search box. Enter the sender in From, check Attachments, and run the search. Review the selected folder or search scope if a message is missing.

Microsoft also documents a Files option for narrowing search results. Use a sender filter as well when you need files from one person. These Outlook tools do not require KAM-Q.

If a file is missing

  • Check the sender address. Search a second address, alias, or shared mailbox separately if the person used one.
  • Include the right folders. In Outlook, widen the search scope. In KAM-Q, check the selected folders and whether indexing has reached those messages.
  • Find the original email. A later reply in a conversation may not include the attachment.
  • Look for a shared link. A OneDrive or SharePoint link in the message body may not be a file attachment. In Outlook, remove the attachment filter and search the sender plus a subject word.

Questions

Does the Outlook query list files or emails?

It finds emails from the specified sender that have attachments. Open a matching message to inspect its files. KAM-Q’s People view offers an attachment list organized by person, and that list can itself be searched by file name or by the subject the file arrived with.

Can I use Outlook’s search without buying KAM-Q?

Yes. The native method uses Outlook’s built-in tools. KAM-Q is an optional way to browse indexed mail and files by sender.

Why is a sender’s KAM-Q file list incomplete?

Check that their messages are in folders selected for indexing and that indexing has reached them. Keep classic Outlook open. If the list still looks wrong, contact support@kam-q.com.
